## 📝 个人学习避坑与 Debug 笔记

在编写 C/C++ 语言数据结构与复杂搜索算法时，需要格外注意以下底层细节：
1. **局部变量初始化**：计算度数或计数器时，在进入循环前务必显式将其重置为 `0`（例如：`n = 0;`），避免因变量复用导致垃圾数据累加。
2. **指针与动态内存释放**：在使用 `malloc` 申请堆内存构建邻接链表或二叉树后，应在程序结束前编写对应的释放逻辑，防范内存泄漏。
3. **数组边界检查**：定义大小为 `N` 的数组时，有效索引为 `0` 到 `N-1`，访问 `N` 会导致非法的数组越界。
4. **DFS 非递归实现与栈**：在实现 DFS 的非递归遍历时，使用辅助栈时需注意在回溯时（即当前顶点的所有相邻节点均已被访问）及时执行退栈操作，否则会陷入死循环。
