## 🛠️ 编译与运行环境

* **编译器**：GCC (MinGW-w64, 建议版本 GCC 15.2.0 或以上)
* **IDE/编辑器**：Visual Studio Code (VS Code)

### 编译运行示例

以邻接矩阵实现为例，您可以在终端中使用 gcc 进行编译和运行：

```bash
# 编译
gcc 5-22_fixed.c -o graph_matrix

# 运行
./graph_matrix
```

## 📝 个人学习避坑笔记

在编写 C 语言数据结构时，需要格外注意以下底层细节：
1. **局部变量初始化**：计算度数或计数器时，在进入循环前务必显式将其重置为 `0`（例如：`n = 0;`），避免因变量复用导致垃圾数据累加。
2. **指针与动态内存释放**：在使用 `malloc` 申请堆内存构建邻接链表后，应在程序结束前编写对应的释放逻辑，防范内存泄漏。
3. **数组边界检查**：定义大小为 `N` 的数组时，有效索引为 `0` 到 `N-1`，访问 `N` 会导致数组越界。
